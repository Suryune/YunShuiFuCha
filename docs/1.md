# 第一章 问苍茫

[回到首页](../README.md)

  “问苍茫大地，谁主沉浮？”  

  语文老师读这句诗的时候，声音拖得很长，带着一点特有的抑扬顿挫。  

  沐明的视线从黑板上的粉笔字，移到了窗外。  

  天很蓝，云很淡，但她的脑子里却塞满了一堆刚刚从数学课上带过来的、长得几乎一模一样的小符号：∈，⊆。  

  它们像某种神秘的咒语。一个是“属于”，一个是“包含于”，界限极其细微，却划定着两个完全不同的世界。

  那个站在橘子洲头的年轻人，想的是“谁来主宰这片大地的命运”。

  而她现在坐在这个四四方方的教室里，面对的却是一张连字母都认不全的数学卷子。

  她不知道自己的未来会构建成怎样的一幅模样，也不确定自己能不能“主沉浮”。

  但她不甘心。

  下了课，她翻开草稿本，在第一页的最上方，郑重地画下了那两个符号。
  这是她的习惯，每当遇到迷惑的墙，就把它们记下来。

  在符号的旁边，她用力写了一行小字：

  “主沉浮。” 

  草稿纸上，冷冰冰的符号和这三个字并排挤在一起，显得极其突兀。

  沐明盯着它们看了好几分钟。久到那些交错的线条仿佛在纸上微微蠕动了起来，而她脑子里依然是一团乱麻。

  她终于转过头，看向同桌陆翎。

  陆翎是个极其喜欢数学的人。下课的时候，沐明总能看到她捧着一些奇怪的书（至少在沐明看来），
  上面画着像树枝一样交错的图，还有一堆冷冰冰的、她看不懂的符号。

  这次，沐明终于没忍住，试探性地敲了敲她的桌角：
  “那个……能不能跟我讲讲，这两个符号到底有什么区别？”

  陆翎从书里抬起头，“嗯”了一声。

  沐明的心里微微紧了一下。

  “区别很简单。”陆翎拿起笔，在草稿纸上画了起来。
  “假如叶子是元素，那么由叶子组成的这棵树，就是集合。如果 A ∈ B，就表示 A 是一片叶子，它长在树 B 上。”

  她又在旁边的枝条上画了一个圈：
  “如果是 C ⊆ B，表示 C 是一根枝条。枝条本身也是由叶子组成的集合，它长在树里。树叶是元素，枝条是集合，它们根本不在同一个维度上。所以你不能用 ∈ 去描述枝条和树，得用 ⊆。”

  沐明盯着那些线条，突然冒出一个问题：“那空集呢？什么都没有的空集，为什么能是所有集合的子集？”

  “这也简单。”陆翎用笔尖轻轻点了点纸面，“空集，你可以把它看作是一根没有叶子的枝条。既然一片叶子都没有，那它自然存在于任何一棵树上。它空得彻底，所以也绝不会和任何一片叶子发生冲突。”

  “还可以这样理解吗？”沐明睁大了眼睛。

  陆翎笑了笑，把笔放下，看着草稿纸上的树影，轻声说：“通往数学的路有很多条。找到最适合你的那一条，最重要。”

  窗外有一阵风路过。

  翻动了书页，也轻轻吹动了草稿纸的一角。

  沐明看着陆翎的眼睛，那一刻她觉得，陆翎说的好像不只是数学。
