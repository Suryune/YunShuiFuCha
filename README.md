# 云水浮槎

本项目为一部探讨哲学、数学与系统论的开源小说。

## 序言

风过的时候，没有声音，只有树叶自己摇晃。

时间的刻度也总是模糊的，回过神来，杯里的水已经凉了。

结局都是一样的。星辰也好，你我的一辈子也好，最后都会暗下去。

那就不去问为什么了。

我只是刚好，想在这个世界上留下一点墨迹。
所以，你看到了这些文字。

就像风穿过山谷，不是为了给谁送信，只是因为它是风。

至于意义，那是你合上这本书之后，你自己的事情了。
